# ReciclaNet - Libro Interactivo

Una aplicación web interactiva que simula un libro sobre reciclaje, desarrollada con React y TypeScript.

## Características

- Interfaz de libro interactivo con animaciones de cambio de página
- Barra de progreso que muestra el avance en la lectura
- Contenido multimedia (videos y audios)
- Diseño responsivo
- Navegación intuitiva

## Requisitos previos

- Node.js (versión 14 o superior)
- npm o yarn

## Instalación

1. Clona este repositorio
2. Navega al directorio del proyecto:
   ```bash
   cd recicla-net-react
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```

## Uso

Para iniciar la aplicación en modo desarrollo:

```bash
npm start
```

La aplicación se abrirá en tu navegador en `http://localhost:3000`.

## Estructura del proyecto

- `src/components/Book.tsx`: Componente principal del libro
- `src/App.tsx`: Componente raíz de la aplicación
- `src/index.css`: Estilos globales
- `public/`: Archivos estáticos y multimedia

## Tecnologías utilizadas

- React
- TypeScript
- TailwindCSS
- Framer Motion (para animaciones)
